# C2C planning docs

One markdown file per feature or investigation for the C2C test suite. Keep design detail
here; keep `CLAUDE.md` (repo root) lean and link out to these.

Suggested naming: `NNN-short-title.md` (e.g. `001-rolling-window-throughput.md`).

Each doc should capture: goal, current state, approach/decisions, open questions, and links
to the relevant `c2c-demos/` targets and any bug-log entries in `CLAUDE.md` it depends on.
